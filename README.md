## 软件简介

D5Render 是一款运行于 Windows 平台的原生 C++ 视觉辅助软件，面向离线场景下的实时屏幕目标检测与辅助瞄准研究。软件通过 DXGI/WGC 桌面捕获获取画面，使用 NVIDIA TensorRT 在 GPU 上执行 YOLO 系列模型推理，配合纯跟踪目标直通、Smith 预估器在途记账与指数收敛控制律实现平滑、稳定的辅助瞄准，全部链路针对低延迟实时性做了深度优化。

**核心架构**

```
屏幕捕获(DXGI/WGC) → GPU预处理(letterbox) → TensorRT推理 → 后处理(NMS/置信度过滤)
     → 目标跟踪器(纯跟踪+身份验证) → 检测框稳定器 → 自瞄控制律(Smith在途记账/指数收敛/曲线平滑/拟人化)
     → 鼠标驱动输出(罗技GHUB) → 预览窗口可视化
```

**技术亮点**

| 模块 | 技术方案 |
|------|---------|
| 屏幕捕获 | DXGI桌面复制（全系统最低延迟），被占用时自动回退WGC，黄字提示实际模式 |
| GPU推理 | TensorRT Engine，稀疏权重优化（Ampere架构提升5-10%），CUDA 12/13 |
| 数据通路 | CUDA pinned内存 H2D 拷贝 + 自旋同步（cudaDeviceScheduleSpin），平均2.0-2.6ms/帧 |
| 目标跟踪 | 纯跟踪原始位置直通 + 有限差分测速 + 逐帧身份验证 + 轨迹重捕 + 类别一致性校验 |
| 检测稳定 | 尺寸EMA+突变冻结 / 置信度EMA / 新轨迹确认门限 / 位置突变拒绝 |
| 自瞄控制 | Smith预估器在途记账 + 指数收敛律（分段τ）+ 曲线平滑 + 死区钉死滞回 + 拟人化抖动（强度0~2.0可调） |
| 输出插值 | 连续输出：检测帧整步折算为控制速率按时间片连续发射，消除步进卡顿 |
| 主循环 | 硬节拍器240fps上限，防止CPU空转烧核 |

## 功能特性总览

### 检测与识别
- YOLO 系列模型推理（支持 416/640 输入尺寸的自定义 ONNX 模型）
- 置信度阈值、NMS 阈值可调
- FOV 视场扇形过滤（仅处理准星周围候选区域，检测区域由模型固定）
- 干扰源预过滤：噪声散点、全屏误检框、细长条纹拖影自动丢弃

### 目标跟踪
- 纯跟踪直通：目标原始检测位置无滤波直通控制律，杜绝预测外推被自身甩枪视角旋转污染；缺检期间保持最后已知位置补位（最长75帧≈1.25秒容忍枪口火焰遮挡）
- 有限差分测速：原始位置逐帧差分估计目标速度，仅用于贴附锁死判定与场景分析
- 目标身份验证：类型一致 + 边界框面积比校验，防止误切换
- 击杀后瞬时切换最近目标，切换冷却与防链式跳变机制
- 检测框稳定器：尺寸EMA + 突变冻结 + 置信度EMA + 新轨迹确认门限 + 锁定目标位置突变拒绝

### 自瞄辅助
- P增益单参数指数收敛律：alpha=1-exp(-dt/τ)，分段时间常数（近区50ms快回咬/远区100ms防过冲），输出=有效误差×alpha，单旋钮调软硬
- Smith预估器在途记账：扣除画面延迟窗口（3帧≈60~100ms）内全部已发送移动量，根治画面延迟导致的反复回修过冲
- 曲线平滑：smoothstep缓动（近距轻柔、远距直给），无状态无拖尾
- 死区钉死滞回：慢速目标贴附后进入锁死态，1.8倍死区内绝对零输出纹丝不动；手动拉鼠标/目标急移自动解锁
- 过冲自抑制：检测到误差反号自动压低增益直到零过冲（开关/压低系数/基准力道均可调）
- 拟人化抖动（可选，默认关）：幅度抖动/弧线轨迹/正弦微扰/高斯噪声四组件，**抖动强度0~2.0滑条用户可调，拉得越大抖动越厉害**；贴附区(误差<20px)自动渐隐关闭
- 最大步长封顶 + 90%硬钳位 + 98%防穿越钳位，杜绝单帧大步甩飞
- 过期帧丢弃：推理帧龄>120ms 直接丢弃，杜绝画面加载卡顿导致的鼠标乱跳

### 人机交互
- 预览窗口：实时轨迹可视化（锁定红框/确认绿框/待确认灰框/保持黄框）
- 状态信息叠加层：帧率、延迟、检测率、锁定状态，字体间距防重叠
- 日志面板：右键可复制单条日志（含时间戳/纯文本两种格式），日志不刷屏
- 伪造最小化：窗口缩至 72×6 像素薄条贴屏幕边缘，Home 键一键切换
- 音效反馈：总开关切换提示音（可关），异步播放不阻塞瞄准
- 总开关记忆：音效开关等设置自动保存，重启保留

### 性能与管理
- GPU 锁频（默认关闭，防止功耗尖峰触发电源保护）
- 捕获帧率与推理帧率自动同步，消除冗余GPU拷贝
- 推理提交速率动态调节（基于实时GPU成本，15%滞回+30fps下限）
- 独立日志文件落盘（exe目录 `d5render_log.txt`，启动重置）
- XOR+Base64 加密配置持久化，防篡改防误改

## 安装与首次运行

### 1. 环境准备
- 安装最新 NVIDIA 显卡驱动（含 CUDA 运行时）
- 安装 [Visual C++ Redistributable 2015-2022 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe)（避免 DLL 链接失败）
- 安装罗技 G HUB 并确保鼠标被 G HUB 接管

### 2. 首次运行
1. **右键以管理员身份运行** `D5Render.exe`（软件默认请求管理员权限，用于游戏内热键注入）
2. 软件自动检测 GPU 并初始化罗技驱动，日志显示 `鼠标驱动: 罗技GHUB驱动` 即为正常
3. 在界面中选择模型文件（如 `DGv26s416.onnx`），点击加载

### 3. 关于首次模型加载（重要）
TensorRT 首次加载新模型文件时会触发完整的 JIT 引擎编译：

| 模型输入尺寸 | 首次编译耗时 | 后续启动 |
|------------|------------|---------|
| 416 | 约 2-3 分钟 | 秒级加载 |
| 640 | 约 10-12 分钟 | 秒级加载 |

> 首次加载期间界面可能无响应提示，**请勿关闭软件**，编译完成后缓存自动保存，之后每次启动均为秒级加载。此为 TensorRT 正常特性。

## 使用指南

### 基本流程

1. **管理员运行** → 2. **加载模型** → 3. **选择捕获模式**（推荐 DXGI）→ 4. **打开预览窗口核对检测框** → 5. **调参**（新手直接用预设）→ 6. **进入游戏** → 7. **按住自瞄热键启用辅助**

### 新手推荐参数（一键起步）

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| FOV | 0.55 | 万金油起点，偏稳定 |
| 确认帧数 | 2 | 默认值，抗干扰与响应速度平衡 |
| 切换阻力 | 0.10~0.25 | 太高（0.5+）极难切换，可能跟错目标 |
| 匹配阈值 | 150 | 默认值，勿动 |
| 最大丢失帧数 | 75 | 默认值，容忍火焰遮挡 |
| 抖动强度 | 1.0 | 需先开启拟人化抖动；0=纯净输出（推荐追求稳定者） |

### FOV 按玩法风格调整

| 玩法 | FOV 推荐 | 说明 |
|------|---------|------|
| 步枪中距离 | 0.50~0.60 | 平衡候选范围与专注度 |
| 栓动狙击/远距离 | 0.35~0.45 | 收窄聚焦当前目标 |
| 近战冲锋 | 0.65~0.75 | 扩大候选应对多目标 |
| 新手起步 | 0.55 | 万金油 |

> **注意**：FOV 超过 0.8 不会扩大可见范围，反而降低对当前目标的专注度。FOV 只影响候选锁定范围，不影响检测区域（检测区域由模型输入尺寸固定）。

### 热键操作

| 热键 | 功能 |
|------|------|
| 自瞄热键（可配置） | 按住启用自瞄辅助，松开停止 |
| Home | 切换伪造最小化（72×6像素薄条 / 恢复窗口），不影响瞄准逻辑 |

## 界面与参数详解

### 检测页

| 参数 | 默认 | 说明 |
|------|------|------|
| 置信度阈值 | 0.25 | 低于此值的检测框被丢弃。**调高**→框更稳但远处小目标可能丢失；**调低**→目标更多但干扰框增多。检测框闪烁时可小幅上调（0.30~0.35） |
| NMS 阈值 | 0.45 | 重叠框抑制强度，一般不动 |
| 捕获模式 | DXGI | 延迟最低；被其他程序占用时自动回退WGC并在日志说明 |

### 自瞄页（全部为真实生效参数，无摆设项）

| 参数 | 默认 | 说明 |
|------|------|------|
| P增益 | 0.30 | 指数收敛律总增益（与速度倍率/基准力道相乘生效）。**调高**→吸附更硬更快；**调高过多**→远/中距摇晃 |
| 死区 | 6 | 误差小于此值不输出；慢速目标贴附后1.8×死区内锁死纹丝不动 |
| 最大步长 | 14 | 单帧最大移动量（屏幕像素量纲）。调小更稳但远距追不上 |
| 曲线平滑 | 0.22 | smoothstep缓动强度：0=直给，越高近距输出越轻柔（远距恒满力） |
| 速度倍率 | 1.0 | 与P增益相乘的总速率旋钮，快速拉满吸附力度 |
| 启用拟人化抖动 | 关 | 模拟人手特征的输出扰动（幅度抖动/弧线轨迹/正弦微扰/高斯噪声），对抗行为统计检测；开枪压枪稳定性略降 |
| 抖动强度 | 1.0 | **拟人扰动总幅度滑条，拉得越大抖动越厉害**：0=无扰动（输出纯净），1=标准拟人，2=强力（扰动翻倍）。需先开启拟人化抖动 |
| 过冲自抑制 | 开 | 误差反号自动压低增益直到零过冲；压低系数0.70/基准力道1.0均可调 |
| FOV | 0.55 | 候选目标范围（见上文推荐表） |
| 目标点位置 | 可调 | 瞄准框内位置（头部偏向/中心） |

### 目标跟踪区

| 参数 | 默认 | 说明 |
|------|------|------|
| 匹配阈值 | 150 | 检测框与轨迹的关联距离上限（含类别/尺寸惩罚），勿随意改动 |
| 最大丢失帧数 | 75 | 轨迹失联多少帧后判死。75帧≈1.25秒，容忍枪口火焰导致的检测中断，防止轨迹判死换ID横跳 |
| 切换阻力 | 0.45 | 切换新目标的难度系数。0=随时切到更近目标（可能乱切）；0.5=极难切换（稳但可能跟错）。推荐0.10~0.25 |
| 确认帧数 | 2 | **目标需连续检出≥N帧才允许成为锁定目标**。拦截枪口火焰/烟雾/特效等单帧干扰框抢锁。1=关闭（旧版行为）；击杀后切新目标会多等1个检测帧（约20-60ms），换取锁定不被干扰框抢走 |

### 检测框稳定器（自动生效）

检测框闪烁/受干扰（0.001秒级被其他事物扰动）是目标检测的固有噪声，软件在轨迹层做了五重稳定，**全部自动生效无需配置**，仅"确认帧数"暴露为UI参数：

1. **干扰源预过滤** —— 噪声点（<5px）、全屏火焰误检框（>90%画面）、细长条纹拖影（长宽比>12）直接丢弃，不进匹配、不建轨迹、不进预览
2. **尺寸EMA+突变冻结** —— 框尺寸逐帧指数平滑；单帧突变超2.5倍判定为干扰，冻结尺寸沿用上帧。遮挡/姿态变化/火焰膨胀不再引发框体跳变
3. **置信度EMA** —— 置信度在阈值边缘振荡（如0.26↔0.51来回跳）时平滑显示，标签%与锁定置信度不再逐帧跳动
4. **新轨迹确认门限** —— 新目标连续检出≥N帧才可被锁定，单帧幽灵框永远抢不走锁
5. **锁定目标位置突变拒绝** —— 非甩枪场景下（目标速度<800px/s），锁定框中心单帧跳变>max(3倍框宽,180px)判定为遮挡偏移框，冻结该帧不拽准星，日志输出 `[抗干扰] 锁定目标位置突变已拦截`

## 配置文件与预设

- 配置文件：exe 同目录 `d5render_config.ini`，采用 **XOR(0x5A滚动密钥)+Base64 编码的二进制配置**，防篡改防误改

- 修改配置前请先关闭软件（运行中的进程可能覆盖写入）
- 版本升级无缝兼容：旧版 ini 自动加载，新增字段使用默认值

## 常见问题 FAQ

### Q1：启动报错 / 界面空白 / DLL缺失
安装 [VC++ 2015-2022 运行库 x64](https://aka.ms/vs/17/release/vc_redist.x64.exe)。仍报错请查看 `d5render_log.txt` 中的具体错误码并反馈。

### Q2：捕获黑屏 / 全黑画面
- **HDR 开启**会导致桌面帧为10bit格式，向8bit纹理拷贝静默失败——请关闭 HDR（日志会有明确提示）
- DXGI 被其他程序独占（NVIDIA App 游戏覆盖层/即时回放、OBS捕获、录屏软件）——关闭对应功能后重启软件

### Q3：帧率暴跌 / 延迟尖峰
- 关闭 NVIDIA App 的 Overlay 与即时回放（注入会拦截捕获链路）
- 游戏帧率建议降至 240fps、直播编码降至 720p30（RTX 30系列满载极限）
- 有双显卡建议将推理迁移至独立第二块GPU

### Q4：检测框闪烁怎么办
软件已内置检测框稳定器自动生效。仍闪烁时可：①上调置信度阈值至 0.30~0.35；②确认帧数调至 3；③预览中观察灰框（确认中）数量判断环境干扰程度。

### Q5：GPU锁频要开吗
**默认关闭，不建议开启**。游戏满载叠加推理负载时锁频会触发 RTX 3080 瞬时功耗尖峰，可能引发电源过流保护导致整机断电重启。

### Q6：退出软件后游戏帧率暴跌
旧版本GPU锁频 bug 已修复：退出时锁频会正确解除。若仍出现请反馈日志。

### Q7：游戏内热键无效
确认软件以**管理员身份**运行（任务管理器查看提权状态）。管理员权限保证全局热键在游戏中生效。

### Q8：模型加载卡住几分钟
首次加载新模型触发 TensorRT JIT 编译（416模型2-3分钟/640模型10-12分钟），属正常特性，编译完成后秒级加载。请勿在首次编译期间关闭软件。

## 已知限制

1. **推理与游戏同卡时无法根治延迟尖峰**：游戏资源加载/特效会抢占GPU产生秒级推理延迟，软件侧已通过丢弃>120ms过期帧防止鼠标乱跳，但物理上唯一根治方案是推理迁移到独立第二块GPU
2. **TRT引擎与显卡强绑定**：换显卡/换驱动大版本需删除引擎缓存重新编译
3. **DXGI桌面复制全系统排他**：同一时刻仅一个程序可持有，冲突时自动回退WGC（延迟略高）
4. **远/中距检测量化噪声**：模型对远距离小目标的框输出存在像素级量化抖动，稳定器可大幅缓解但无法100%消除
