软件概述

D5 Render 是一款基于 YOLO 目标检测模型的视觉辅助软件，采用 C++ 原生开发，结合 TensorRT / DirectML 推理加速和 CUDA GPU并行计算，实现超低延迟的实时目标检测与辅助。

双推理引擎
支持 TensorRT(NVIDIA专属极速)和 DirectML(通用GPU兼容)双引擎切换，适配不同硬件环境
CUDA零拷贝
CUDA-D3D11互操作实现屏幕捕获到推理的 零CPU拷贝路径，延迟降低1-2ms
PD控制瞄准
PD控制器 + 惯性平滑 + 最小移动速度 + 零过冲硬钳位，参数精简直观，新手即调即用
多重鼠标驱动
支持 罗技专用驱动、Makcu硬件盒子、通用驱动三种鼠标驱动方式

运行环境准备

  1. 安装 NVIDIA 显卡驱动（最新版），确保显卡支持 CUDA
  2. 将程序完整文件夹解压到任意目录，所有必需 DLL 已自带，无需单独安装 CUDA Toolkit、TensorRT、ONNX Runtime 等
  3. 检查程序目录下 DLL 是否齐全：cudart64_*.dll、cublas64_*.dll、cudnn64_9.dll、nvinfer*.dll、onnxruntime.dll、DirectML.dll 等
  4. 如需Makcu盒子，安装 CH343串口驱动 并连接Makcu硬件
  5. 准备一个 YOLO ONNX 模型文件（支持 V5~V26 各版本），放入程序目录
提示 本程序已整合所有运行时依赖（含cuDNN），只需复制整个 bin 文件夹即可使用。所有 DLL 均与 exe 位于同一目录。
罗技用户 logitech.driver.dll 和 ghub_device.dll 已包含在程序目录中。如不可用，请安装罗技G HUB软件，程序运行时会自动搜索并加载。

首次运行

  1. 以 管理员权限 启动 D5Render.exe
  2. 点击 「选择模型」 按钮，浏览并选择你的 YOLO ONNX 模型文件
  3. 确认模型版本被自动识别（右上角显示绿色版本标签）
  4. 根据硬件选择 推理模式（TensorRT 或 DirectML）
  5. 点击 「加载模型」，等待模型加载完成（首次加载TensorRT引擎需几分钟构建）
  6. 设置 按键（默认为鼠标侧键X1），按住按键即可激活
  7. 按 Home 键可快速隐藏/显示程序窗口

模型设置

D5 Render 使用 YOLO系列目标检测模型，仅支持 .onnx 格式。模型的选择直接决定检测效果，请确保模型训练场景与实际使用场景匹配。

YOLO版本识别

软件支持从 YOLOv5 到 YOLOv26 共8个版本的模型：

版本输出特征自动识别
V5基于锚框 (3个预设框)根据输出维度d1==3识别
V6无锚框需手动指定
V7基于锚框根据输出维度识别
V8无锚框 (默认)默认版本
V9无锚框需手动指定
V10端到端 (无需NMS)根据输出维度识别
V11无锚框需手动指定
V26端到端根据端到端输出推断
关键 版本 自动识别 标志：绿色 = 识别成功，黄色 = 未识别（使用默认V8）。如检测结果不准，请手动切换版本。

推理模式选择

TensorRT (推荐)

优势：速度最快，延迟最低
支持：零拷贝（CUDA-D3D11互操作） + CUDA Graph优化
精度：FP16半精度/FP32全精度可选，混合精度优化
要求：NVIDIA专用，需安装CUDA+TensorRT

DirectML (兼容)

优势：通用GPU加速，兼容AMD/Intel
支持：通过TensorRT EP实现GPU加速
精度：FP16半精度，引擎缓存加速
要求：NVIDIA显卡(需cuDNN)或兼容DirectML的GPU

推荐 有 NVIDIA 显卡 → 选 TensorRT；无法使用TensorRT → 选 DirectML。DirectML模式也使用TensorRT EP加速，需要cuDNN DLL支持。

TRT精度配置

TensorRT 模式下提供两种精度选择：

精度速度精度显存适用场景
FP16 半精度最快可能轻微抖动减半日常使用，推荐首选
FP32 全精度稍慢最高翻倍需要极高精度时

混合精度优化

在TRT精度选择 FP32全精度 后，可开启 混合精度优化，允许部分层使用FP16加速，性能较好的显卡开启后速度接近纯FP16，同时保持FP32精度优势。

显卡选择

如果你的系统有 多张显卡，可以指定用于推理的显卡：

  • 0 = 第一张显卡（默认）
  • 1 = 第二张显卡
注意 切换显卡后需 重新加载模型。推理运行中无法切换，请先停止检测。

检测阈值

置信度阈值

目标被识别的 最低可信度。低于此阈值的目标将被忽略。

范围效果推荐值
0.01 ~ 0.20识别极多，误判多不推荐
0.25 ~ 0.50平衡检测率与准确率推荐
0.50 ~ 1.00识别极准，可能漏检特殊场景

NMS阈值（非极大值抑制）

控制重叠检测框的去重程度：

  • 越低 = 重叠框越少（更严格去重）
  • 越高 = 保留更多重叠框
  • 推荐默认 0.45

预设模式

软件提供 预设模式，一键切换参数组合：

默认模式 — 稳定锁定

采用 PD控制 + 惯性平滑 + 最小移动速度 + 零过冲钳位 的精简方案：

  • Kp=0.30, Kd=0.15, 死区=5
  • 速度倍率=1.0, 最大步长=18, 惯性=0.20
  • D项仅制动(接近目标时减速)，永不加速
  • 最小移动速度2px/帧，确保快速锁定不爬行
  • 移动量硬钳位在误差的90%内，数学保证零过冲
  • FOV自动缩放开启，锁定后缩小到0.15
  • 场景自适应开启，复杂场景自动调整参数
  • 卡尔曼滤波开启，过程噪声=12，测量噪声=2
刷新率自适应：首次启动（无配置文件时），软件会自动检测屏幕刷新率并调整默认参数：
  • 60~75Hz：使用上述基准参数（缩放1.0）
  • 100~120Hz：Kp/步长/惯性 × 0.85
  • 144~165Hz：Kp/步长/惯性 × 0.70
  • 240Hz+：Kp/步长/惯性 × 0.60
已有配置文件时保留用户设置，不受刷新率影响。

自定义模式 — 用户保存

点击 「+」 按钮可将当前所有参数保存为自定义预设，下次启动仍可使用。

目标选择策略

距离优先
选择离准心 最近 的目标，锁定后持续跟踪，不会随意切换。适合大多数场景，默认推荐。
大小优先
选择画面中 最大 的目标（通常距离最近），锁定后持续跟踪。适合需要优先处理近距离目标的场景。
锁定机制 无论哪种策略，锁定后不会乱切目标，直到目标消失超过容忍帧数或松开热键才释放锁定。锁定粘性持续约1秒，期间不会跳到其他目标。

自瞄总开关

自瞄总开关是一个 独立的全局开关，控制自瞄功能是否生效。启用后，即使按住瞄准键，也只有在总开关为 ON 状态时才会锁定目标。

核心用途 防止局外（大厅、选英雄、结算界面等）误锁目标。左键自瞄用户尤其需要——局外UI元素可能被误识别为目标，导致鼠标异常移动。

启用总开关

勾选 「启用总开关」 复选框后，热键切换功能生效。状态指示实时显示：

  • 绿色 [ON] = 总开关已开启，按住瞄准键即可锁定
  • 红色 [OFF] = 总开关已关闭，按住瞄准键也不会锁定

按键模式

模式说明适用场景
单键按一个键切换开/关简单快捷，局外关一下即可
组合键需同时按住两个键才切换防误触，推荐局内使用

按键选择

主键和组合键均支持 72个按键，包括：

  • 鼠标键：左键、中键、右键、侧键1、侧键2
  • 修饰键：左/右 Shift、Ctrl、Alt
  • 数字键：1~0（大键盘）
  • 字母键：A~Z（全26键）
  • 特殊键：Tab、CapsLock、Space、Enter、Backspace
  • 功能键：F1~F12
  • 导航键：Ins、Home、End、PgUp、PgDn、Scroll、PrtSc、Pause
推荐配置 单键模式：F10 或 F11（默认）
组合键模式：Ctrl+Q、Ctrl+F10 等（主键+修饰键）

运行逻辑

  1. 总开关 未启用 → 行为与之前完全一致，按住瞄准键即可激活
  2. 总开关 启用+OFF → 按住瞄准键不会锁定目标
  3. 总开关 启用+ON → 按住瞄准键正常锁定目标
  4. 每次启动程序，总开关默认为 OFF，防止意外激活

按键模式

控制自瞄激活的按键方式，支持 单键 和 组合键 两种模式：

模式说明示例
单键按住一个键即激活鼠标侧键X1（默认）
组合键需同时按住两个键Alt + 鼠标侧键

按键设置方式：点击按键按钮 → 按下任意键 → 自动识别绑定。按 Esc 可取消捕获。

多按键管理

支持最多 10个按键槽，任意一个按键槽按下即可激活：

  • 每个按键槽可独立设置 单键 或 组合键 模式
  • 点击 「+ 添加按键槽」 将当前按键设置转为第一个槽
  • 可继续添加更多按键，最多10个
  • 右键自定义预设按钮可删除预设
  • 点击 「清空所有按键」 恢复单按键模式

PD控制与移动参数

核心算法采用 PD控制器 + 惯性平滑 + 最小移动速度 + 零过冲钳位，参数精简、直观易调：

v1.0.7 防检测增强 新增 Home 键窗口显隐切换（全屏游戏下隐藏/找回配置面板）、窗口随机化标识（类名/标题每次启动随机生成，破坏特征匹配）、移动输出拟人化层（叠加幅度抖动/弧线侧偏/正弦微扰/高斯噪声，对抗行为统计检测）。
v1.0.6 精简优化 移除了积分项(Ki)、平滑度、加速曲线、精细距离、抖动随机化等复杂参数，仅保留 Kp、Kd、死区、速度倍率、最大步长、惯性 六个核心参数，对新手更友好，调参更直观。

PD参数

PD控制器是瞄准算法的核心，决定鼠标移动的响应特性：

比例增益 Kp

控制鼠标移动到目标的 基础响应速度：

  • 0.1 ~ 0.2 = 慢速响应，非常平滑但反应慢
  • 0.25 ~ 0.35 = 平衡响应，推荐
  • 0.35 ~ 0.50 = 快速响应，灵敏但需注意过冲
  • 默认值 0.30
公式 移动量 = 误差 × Kp × 速度倍率，Kp越大每帧移动越多。系统硬钳位确保移动量永远不超过误差的90%，因此即使Kp调大也不会过冲。

微分增益 Kd

抑制 过冲和振荡，接近目标时自动减速制动：

  • 0 = 无制动，纯比例控制，可能轻微过冲
  • 0.10 ~ 0.20 = 适度制动，推荐
  • 0.20 ~ 0.50 = 强制动，接近目标时减速明显
  • 默认值 0.15
D项特性 D仅在接近目标时制动（误差减小时减速），目标远离时不加速，最多削减P的50%。即使Kd拉满也不会导致准心反向抖动。

速度倍率

所有移动的全局 速度缩放：

  • 0.5 = 半速，非常平滑
  • 1.0 = 正常速度（默认）
  • 1.5 ~ 2.0 = 加速，快速锁定

移动参数

参数默认值范围说明
最大步长181 ~ 50每帧最大移动像素，防止瞬间大跳
惯性0.200 ~ 0.95上帧移动的保留比例，越大越平滑

零过冲保障机制

v1.0.7 采用多重保障确保 零过冲：

  • 90%硬钳位：移动量永远不超过剩余误差的90%，数学上不可能越过目标
  • 最小移动速度2px：误差小时确保准星不爬行，快速锁定目标
  • D制动限制：D最多削减P的50%，不会反转移动方向
  • 跳帧零移动：检测间隔帧不移动，防止累积过冲

吸附位置Y

控制Y轴方向的 吸附偏移：

  • 0 = 头部（适合爆头）
  • 0.5 = 身体中心（最稳定）
  • 1 = 脚部（不推荐）
  • 推荐 0.0 ~ 0.3

吸附位置X

控制X轴方向的吸附位置：

  • 0 = 目标左边缘
  • 0.5 = 目标中心（默认）
  • 1 = 目标右边缘

按类别瞄准位置

勾选 "启用按类别独立设置" 后，可为每个类别单独配置Y轴吸附位置，全局吸附位置Y将自动隐藏。

  • 仅在 上方类别筛选 中勾选的类别才会显示设置滑块
  • 取消勾选的类别 不被检测，但已设置的数值会保留
  • 每个类别独立设置Y轴位置，互不影响
使用示例：
  • 敌人类别设为 0.35（脖子位置）—— 稳定锁定，适合中距离
  • 小兵类别设为 0.25（头部偏上）—— 一枪爆头，节省子弹
  • BOSS类别设为 0.5（身体中心）—— 稳定输出弱点

FOV视野范围

自瞄搜索目标的 圆形视野范围：

  • 1.0 = 整个捕获区域
  • 0.1 = 仅屏幕中心附近
  • 推荐 0.30 ~ 0.60

FOV自动缩放

启用后，锁定目标时会 自动缩小 检测范围，减少其他目标干扰：

参数说明推荐值
锁定FOV缩小后的视野范围0.10 ~ 0.20
缩放速度FOV缩小的速度5.0 ~ 10.0
还原速度目标消失后FOV恢复的速度2.0 ~ 5.0

死区设置

准心与目标距离 小于死区值 时停止移动，防止锁定后的微调抖动：

死区(像素)效果适用场景
0完全无死区，始终微调不推荐 会抖动
3小死区，精准锁定近距离/高精度需求
5适中死区，锁定稳定且精度足够推荐（默认）
8~10大死区，锁定更稳但精度略低远距离/高抖动场景
说明 死区是在 误差距离 上判断的，不是单个轴。死区5px意味着误差距离小于5px时完全停止移动。配合最小移动速度2px/帧，准星能快速收敛到死区内并稳定锁定。

自动扳机

自动扳机功能可在 准星到达目标时自动按住左键开枪，适用于全自动武器（步枪、冲锋枪等）的持续射击场景。

核心流程

  1. 按住 自瞄键 锁定目标，自瞄系统将准星移向目标
  2. 同时按住 自动扳机触发键（如鼠标侧键2）
  3. 准星与目标中心的距离 ≤ 触发阈值时，自动按住左键持续开枪
  4. 准星偏离目标超过阈值时，自动释放左键停止射击
关键特性
  • 持续按住：进入触发区后按住左键不放，游戏自身控制射速，可完整清空弹夹
  • 智能释放：准星偏离目标或松开触发键时立即释放左键
  • 受总开关控制：自瞄总开关必须开启才能使用自动扳机
  • 与对狙互斥：对狙触发时自动扳机暂停

参数说明

参数默认值范围说明
启用自动扳机关闭开/关启用自动扳机功能
触发键无72个按键按住此键激活自动扳机，推荐鼠标侧键2
开枪延迟(ms)500 ~ 500准星到位后延迟多少毫秒再开枪，模拟人类反应时间
触发阈值(px)5.00.5 ~ 30.0准星距目标中心≤此像素数时判定到位并开枪
拟人化随机开启开/关随机化触发阈值和开枪延迟，模拟人类操作
注意
  • 开枪延迟 0ms = 准星到位立即开枪，最快但最容易被检测，推荐 50ms
  • 触发阈值越小 = 要求准星越精准才开枪（5px推荐），越大 = 越容易触发但可能打不中
  • 玩家手动按住左键开枪时，自动扳机不会干扰手动操作

对狙设置

对狙功能专为狙击枪设计，实现 瞬间吸附 + 自动开枪 的一键秒杀操作。

核心流程

  1. 用户看到目标，右键开镜
  2. 准星接近目标后，按下 触发键（如鼠标侧键1）
  3. 软件瞬间将准星吸附到目标头部（80%距离瞬间跳 + 20%自瞄修正）
  4. 延迟指定帧数后自动点击左键开枪
关键特性
  • 固定瞄头：对狙始终锁定目标头部，不受Y轴吸附位置参数影响
  • 独立触发：不需要按住自瞄键，只需按触发键即可执行
  • 受总开关控制：自瞄总开关必须开启才能使用对狙

参数说明

参数默认值范围说明
启用对狙关闭开/关启用对狙功能
触发键鼠标侧键172个按键按下此键触发吸附+开枪，推荐鼠标侧键
开枪延迟(帧)30 ~ 20吸附后等待帧数再开枪，0=立即开枪，3≈50ms@60fps（推荐）
注意 开枪延迟设置过小（0~1帧）可能在准星尚未到位时就开枪导致空枪，建议设为 3帧 以上。延迟过大则会错失时机。

目标追踪

目标追踪模块确保锁定目标的 稳定性和持续性：

匹配阈值

目标重识别的搜索半径（像素）：

  • 越小 = 仅匹配近距离目标，更精确但易丢失
  • 越大 = 远距离也能匹配，更宽容但可能误匹配
  • 推荐 100 ~ 150

丢失容忍

目标消失后保持追踪的 帧数：

  • 越小 = 快速放弃丢失目标
  • 越大 = 长时间保持追踪，对短暂遮挡越容忍
  • 推荐 15 ~ 25

切换阻力

目标切换的阻力系数，防止锁定目标频繁切换：

  • 0 = 随时切换到更近目标
  • 0.5 = 极难切换
  • 推荐 0.10 ~ 0.25

常见问题

Q：模型加载失败，提示"TensorRT EP不可用"？

A：DirectML模式依赖TensorRT EP和cuDNN，请检查：

  • 程序目录下是否有 cudnn64_9.dll、cudnn_ops64_9.dll 等cuDNN DLL
  • 是否有 onnxruntime_providers_tensorrt.dll
  • 如cuDNN缺失，从NVIDIA官网下载cuDNN 9.x for CUDA 13，将bin/x64/下所有DLL复制到程序目录

Q：为什么提示"未以管理员权限运行"？

A：鼠标驱动需要管理员权限才能在游戏中正常工作。请右键程序 → 以管理员身份运行。

Q：推理延迟很高/游戏卡顿？

A：尝试以下优化：

  • 使用 FP16半精度 替代FP32
  • 降低模型输入尺寸（使用更小的模型）
  • 确保零拷贝和CUDA Graph已启用
  • 关闭预览窗口减少资源占用
  • 关闭Windows 游戏模式（设置→游戏→游戏模式），游戏模式会优先分配GPU给游戏导致推理延迟暴增
  • 确认GPU驱动为最新版本

Q：锁不住目标/吸附力太弱？

A：调整以下参数：

  • 提高Kp（0.35~0.50），增加基础响应速度
  • 提高速度倍率（1.0~1.5），全局加速
  • 增大最大步长（18~25），允许每帧移动更多
  • 减小死区（3~5），避免锁定过早停止
  • v1.0.6已内置最小移动速度2px/帧，确保不爬行

Q：开枪后准心往上漂？

A：这是后坐力推准心导致的，调参建议：

  • 降低Kp（0.20~0.30），减少基础响应
  • 增大惯性（0.25~0.40），增加平滑抑制
  • 适当提高Kd（0.15~0.25），增强制动

Q：左右过冲/越过目标？

A：v1.0.6已从算法层面保证零过冲（90%硬钳位），如仍感觉过冲：

  • 降低Kp（0.20~0.25），减少每帧移动量
  • 适当提高Kd（0.20~0.30），增强接近目标时的制动
  • 减小最大步长（10~15），限制每帧移动上限
  • 增大死区（5~8），更早停止

Q：目标频繁切换/锁不住？

A：

  • 算法已内置锁定粘性：锁定目标存活时绝不切换，需丢检8帧以上才切换
  • 开启 FOV自动缩放，锁定后缩小搜索范围
  • v1.0.6已修复追踪器丢匹配时即时重获取，不再晃悠半天才锁住

Q：罗技驱动不可用？

A：罗技驱动需要双重检测通过：①LGHUB客户端正在运行 ②驱动DLL可用。请确认：

  • 罗技G HUB软件已安装且 正在运行（检查任务栏图标）
  • logitech.driver.dll 在程序目录中
  • 如不可用，请切换至通用驱动或Makcu模式

Q：Makcu盒子连接失败？

A：参考上方 Makcu连接配置 章节的故障排查步骤。
